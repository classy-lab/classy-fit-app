# React Native App

This repository contains code for a React Native app. It is an app that provides income for Gyms and is fun for members to use. The app contains features for authenticated gym owners, trainers and members which include membership renewals, product sales, group class registrations, private training registrations, gym earnings per category for week, month, year. It shows current business expenses, can list gym equipment, show manufacturer and repair technician contacts, provides member notifications and more. For anonymous users, this app provides basic gym information such as about, contact, gym hours, login and registration screens. App provides a clean UI that is fun to use while aiming to provide a complete solution for gym owners to run and maintain their gym business.
